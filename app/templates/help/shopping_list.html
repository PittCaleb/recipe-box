Sending ingredients to your shopping list

On a recipe, the {{ icon('cart-plus', 16) }} button next to an ingredient adds that one item, and Add all to shopping list adds everything (combining repeats, like butter used in two places). Items arrive as Heavy whipping cream (2 cups) — the name first, the amount in parentheses, matching whatever the scale slider is set to. Lines with no amount, like “salt to taste,” are left out.

The app hands the items to an Apple Shortcut on your own device, which adds them to Reminders. Set it up once on each iPhone, iPad, or Mac you use.

Set up the Shortcut

  1. Open the Shortcuts app and tap + to make a new shortcut.
  2. Name it exactly {{ shortcut_name }} (tap the name at the top, then Rename).
  3. Add the Split Text action. Tap its text field and choose Shortcut Input, and make sure it splits by New Lines.
  4. If a line appears at the top saying it receives input from Nowhere, tap it and choose Share Sheet so the shortcut can accept text.
  5. Add Repeat with Each, set to repeat with each item in Split Text.
  6. Inside the repeat, add Add New Reminder. Set the reminder text to Repeat Item — not Split Text, which would add the whole list as one reminder — and the list to your shopping list (for example Groceries). It should read Add Repeat Item to your list.
  7. Tap Done.

Menu names shift a little between iOS and macOS versions, but those are the four pieces: take the input, split it into lines, and add a reminder for each line.

Try it

Open any recipe and tap {{ icon('cart-plus', 16) }} next to one ingredient. The first time, the app asks whether the Shortcut is set up — choose It’s set up — send. On iPhone and iPad you’ll be bounced to Shortcuts and straight back here; on a Mac it runs in the background. Check Reminders for the item.

If nothing shows up, open the Shortcut and check its name matches {{ shortcut_name }} exactly.

Sharing it with the family

Shortcuts you make sync to your other Apple devices through iCloud. To give it to someone else, open the shortcut’s menu, choose Share → Copy iCloud Link, and send them the link. If your shopping list is a shared Reminders list, everyone’s additions land in the same place.

No Shortcut, or not on an Apple device?

Use the {{ icon('copy', 16) }} button next to Add all to shopping list to copy the list as text, one item per line, and paste it into any notes or list app.
